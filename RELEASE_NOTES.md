# Version 1.0.0

Initial public release of the Canadian Software Procurement Notice Dataset.

## Included

- 136 qualified Canadian public software procurement notices
- 109 notices identified as a Request for Proposal or an RFP against a supply arrangement
- CSV and JSON record files
- Aggregate benchmark summary
- Official source manifest with SHA-256 hashes
- Methodology, data dictionary, citation metadata, and source licence attribution

## Scope

The release is complete for the documented classifier and review method across the listed CanadaBuys source files. It is not statistically representative of all Canadian procurement or private-sector software projects. Requirement flags capture explicit text signals and do not establish that unflagged requirements were absent.
